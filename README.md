# Cybersecurity Journey

Мой практический путь изучения кибербезопасности, Linux, OSINT, сетей, Python и безопасной разработки.

## Цели

- Освоить фундаментальные навыки кибербезопасности.
- Вести структурированные конспекты и практические работы.
- Создать портфолио учебных проектов.
- Работать этично, законно и только в разрешённых средах.

## Структура

- `notes/` — конспекты
- `practice/` — практические задания
- `scripts/` — учебные скрипты
- `ctf/` — заметки по CTF-платформам

## Статус

Day 0: подготовка рабочей среды.
